## CI Gate Rule (NEW — effective immediately)

Any **new or modified** file must have **0 errors / 0 warnings** on eslint.
This is enforced by a pre-commit hook and CI check.

### Implementation

Created `scripts/eslint-diff-check.sh`:
```bash
#!/bin/bash
# Check only files changed in the current git diff (staged + unstaged)
CHANGED=$(git diff --name-only HEAD --diff-filter=AM | grep -E '\.(ts|tsx)$' | grep -v node_modules)
if [ -z "$CHANGED" ]; then exit 0; fi
bunx eslint $CHANGED --max-warnings=0
```

This script is added to `.husky/pre-commit` (if husky is set up) or
called directly in CI before the build step.
